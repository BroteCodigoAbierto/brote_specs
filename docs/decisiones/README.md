# Decisiones

Un registro corto por cada decisión de arquitectura o de forma de trabajo:
qué se decidió, por qué y qué se descartó. Sirven para no volver a discutir lo
mismo y para poder explicar el proyecto.

- Una decisión no se edita para cambiarla: se escribe una nueva que la
  **reemplaza**, y en la vieja se cambia el estado a "Reemplazada por NNNN".
- Formato del nombre: `NNNN-titulo-corto.md`.
