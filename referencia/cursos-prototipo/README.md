# Cursos del prototipo

Copia sin cambios de `data/courses/` del prototipo (`brote_codigoabierto`, rama
`claude`). Usan el formato viejo (campos en inglés: `type`, `answer`, ...),
descrito en `docs/prototipo.md`.

Sirven como datos de prueba y como entrada para la importación (F07).
`git-esencial` es el más completo: usa casi todos los tipos de actividad.

| Carpeta | Curso | Lecciones |
|---|---|---|
| `git-esencial` | Git esencial | 6 |
| `japones-sencillo` | Japonés sencillo | 4 |
| `c-sencillo` | Programación en C sencilla | 4 |
| `examen-unidad-1` | Examen unidad 1 (HTML y Flexbox) | 11 |
